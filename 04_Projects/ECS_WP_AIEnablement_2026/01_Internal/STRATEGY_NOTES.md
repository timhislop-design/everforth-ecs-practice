# Strategy Notes — ECS_WP_AIEnablement_2026

## Core decisions (2026-07-30)
- **Engines, not point tools.** 27 asks (3 contributions) → 4 engines + meeting-intelligence evidence stream + builder-assistance applications + CoE standing function. Any new capability request maps to an engine first (CoE intake rule).
- **Sales first.** Biggest business gap is new sales/pipeline → Phase 1 is entirely capture-side (opportunity monitor, shredder + Bid/No-Bid scorecard, PP matcher).
- **Library as corpus.** Existing OOTB collateral (~150 built artifacts) seeds every capability; nothing generated from a blank page.
- **Review before automate.** Just-in-time collateral reviews by role by stage (guidebook §8), one phase ahead of the capabilities that consume that shelf.
- **Part-time honesty.** 3–5 people × 4–8 hrs/wk ≈ half an FTE. ~12-month arc, 2–3 week increments, formal pause rule, minimum viable phase scope.
